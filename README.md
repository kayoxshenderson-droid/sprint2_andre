Introdução
Neste trabalho foi utilizada uma base de dados da Netflix para fazer analises
utilizando Python. O objetivo foi entender melhor os dados da plataforma através 
de gráficos e estatísticas descritivas.
Durante o desenvolvimento foram utilizados conceitos aprendidos em aula para 
organizar os dados e gerar informações importantes sobre os filmes e séries.
Ferramentas Utilizadas
As ferramentas utilizadas foram:
• Python; 
• Pandas; 
• Matplotlib. 
Essas bibliotecas ajudaram no tratamento dos dados e na criação dos gráficos.
Análises Realizadas
Foram feitos 4 tipos de gráficos:
• gráfico de setores (Pizza); 
• gráfico de barras; 
• histograma; 
• boxplot. 
O gráfico de setores mostrou a porcentagem de filmes e séries.
O gráfico de barras mostrou os países com maior quantidade de títulos na 
plataforma.
O histograma ajudou a visualizar os anos de lançamento dos conteúdos.
O boxplot foi utilizado para analisar a duração dos filmes e observar diferenças 
entre os valores.
Estatística Descritiva
Também foram realizadas análises univariadas utilizando:
• média; 
• mediana; 
• moda; 
• variância; 
• desvio padrão; 
• quartis; 
• valores mínimos e máximos. 
Essas medidas ajudaram a entender melhor o comportamento dos dados 
analisados.
Resultados Obtidos
A análise mostrou que a maioria dos conteúdos da Netflix são filmes.
Também foi possível perceber que nos anos mais recentes houve um aumento 
maior de lançamentos, mostrando crescimento da plataforma ao longo do tempo.
Os países com mais produções apareceram com destaque nos gráficos, 
indicando uma concentração maior de conteúdos em algumas regiões.
Na análise das durações foi observado que alguns filmes possuem tempo muito 
acima da média, o que acabou aparecendo no boxplot.
Contribuição para Tomada de Decisão
Os resultados podem ajudar empresas a entender melhor os padrões dos 
conteúdos e identificar tendencias de mercado.
As informações analisadas também podem auxiliar na organização do catálogo e 
em futuras decisões relacionadas aos tipos de conteúdos mais produzidos.
Além disso, os gráficos ajudam bastante na visualização dos dados, deixando as 
informações mais faceis de entender.
Conclusão
Com este trabalho foi possível aplicar conhecimentos de Python e análise de 
dados vistos durante as aulas.
Os gráficos e medidas estatísticas ajudaram na interpretação das informações da 
base da Netflix e permitiram observar padrões importantes nos dados.
O desenvolvimento do projeto ajudou bastante no aprendizado da manipulação 
de dados e geração de gráficos utilizando programação.
